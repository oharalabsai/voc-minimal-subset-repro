# voc-minimal-subset — reproduction package

Generated by the Ohara autoresearch harness from campaign `voc-minimal-subset`. Every number in `paper/` is an output of the sealed, deterministic verifier shipped here, re-checkable in one command.

## Reproduce (one command)

```
pip install -r requirements.txt
python reproduce.py
```

`reproduce.py` re-runs the verifier's own integrity checks (dress rehearsal and per-modality leverage) and re-verifies every certified hit in `ledger.jsonl`, asserting each still returns `valid:True`. It exits 0 on success.

## Contents

- `workspace/` — the sealed verifier `workspace/verifier.py` (the sole oracle)
- `ledger.jsonl` — the hash-chained ledger: every run, claim, and certified hit
- `contract.json` / `CONTRACT.md` — the frozen public problem contract
- `experiments/` — scored candidates with their verdict JSONs (if any)
- `PRIORS.md` / `JOURNAL.md` / `AUDIT.md` — belief state, decision trail, adversarial audit
- `paper/` — the LaTeX source and compiled PDF
- verifier/battery: NOT included (campaign still live — the battery stays blinded until close).

## How it was produced

A pre-registered contract frozen before any grading, a blinded verifier as the sole oracle (nothing self-reported enters the ledger), independent re-verification of every claimed hit, and an adversarial multi-critic audit before the paper. The paper is human-authored (byline law) with an AI-contribution statement.
